L7	-	Application  Layer		: http, https
L6	-	Presentation Layer		: TLS/SSLs or ASCII or UTP8: data encryption, data translation, and compression happen. 
L5	-	Session Layer			: opens, manages, and closes the connections. 
L4	-	Transport Layer			: TCP, UDP, TLS : Moves data between applications using a port number. TCP guarantees delivery and ordering. 
L3	-	Network Layer			: IP, TCMP : it finds a path from one network to another network using an IP address. 
L2	-	Data Link Layer			: MAC/Switch : it pockets a connection between connected devices on the same network. 
L1	-	Physical Layer			: cable/fiber : the physical reality: zeros and ones as electrical, radio, or light signals

How do you troubleshoot if your instance is unhealthy in a target group? 
- Is your instance in the running state?
- Verify whether the instance security group's required port is open or not.
- Verify the health check path you configured. Make sure your path exists in your EC2 instance.
- Verify whether the application running inside your EC2 instance is working on that port or not.
- Verify your application's running status. Is our application really running or not?
- Make sure your load balancer is added with all subnets.
